# Anchor iOS 高保真原型

Anchor 是面向多 AI 并行工作者的注意力副驾驶。它不替代任务工具，而是持续保留三类最容易丢失的信息：用户最初的目标、各进程的实时状态、离开后重新进入工作所需的上下文。

## 运行

```powershell
npm install
npm run dev
```

默认入口：`http://127.0.0.1:4173/`

直接进入“建立新锚点”：`http://127.0.0.1:4173/?setup=1`

生产构建：

```powershell
npm run build
```

## 核心状态

1. **建立锚点**：开始工作前记录目标、完成标准和 1-6 个并行进程；支持文字与语音输入。
2. **专注副屏**：以目标为锚，展示 2-6 个任务的状态、进度和判断节点。底部圆形 Anchor 用于随时记录判断、下一步或上下文，投锚不会改变工作状态。
3. **横屏 Ambient 状态**：手机横放在 Mac 一侧时切换为远距扫读副屏。关键数字、环境状态和最新事件分成三层；待判断任务只在右栏形成唯一视觉焦点，投锚与确认分别位于左右下方拇指热区。
4. **离开模式**：离开由设备状态自动识别；目标被压缩，需要判断的内容独立分组，运行进度继续变化，App 内没有手动离开按钮。
5. **返航恢复**：检测到用户返回后自动展示原目标、离开期间的变化、当前阻塞点和恢复顺序。返航页的圆形 Anchor 仍只负责记录，“继续工作”才结束返航。

辅助页面包括工作脉络、任务详情、目标编辑、通知、工作结束总结、个人数据、连接与提醒设置。

## Xcode 对照

- `orientation: portrait / landscape` 驱动设备容器和专用横屏布局，不依赖浏览器窗口方向。
- `presence: desk / away` 对应系统识别出的在工位与离开状态；设备外“原型控制器”只用于模拟前端体验，不属于 iOS App。
- `page: home / insights / profile / setup` 对应一级主页、二级脉络、我的页面和新工作流程。
- `sheet: anchor / task / goal / notifications / menu / finish / return` 对应投锚记录、常规 iOS Sheet 或返航全屏 Cover。
- `anchorRecords` 保存本次原型会话中的投锚记录；首页与返航页共用同一套记录能力。
- `src/data.js` 定义原型任务、返航变化和通知数据；接入真实数据层时可保持界面状态结构不变。
- 颜色来自“糖果港湾”令牌：纸白 `#FFF8ED`、物件白 `#FFFDF8`、深海蓝 `#123B53`、海沫绿 `#91DDC4`、珊瑚橘 `#FF7B62`、沙黄 `#F7BD3C`、天空蓝 `#59CBD0`、长春花紫 `#8B84F7`。深海蓝承担主 CTA，`#3479B9` 仅用于链接和次级导航。
- 竖屏采用底部安全区，横屏采用左侧 Dynamic Island 轨与右侧 Home Indicator；卡片材质与尺寸规范见下节。

### P0 / P1 材质契约

- 主卡圆角 26-28pt，重复任务卡 24pt，内嵌选择卡 18-20pt，命令按钮与状态标签使用 capsule；图标容器使用 11-15pt squircle。
- 卡片不使用 1pt 外描边。边界由同色浅底、彩色软阴影和顶部内高光建立；选中态使用 3pt 外发光环，不改卡片几何。
- 拉丁字母和数字使用本地 Nunito Variable，中文回退到系统黑体；动态数字必须启用 tabular figures。任务主数字在竖屏使用 24-28pt、横屏使用 30-38pt 圆体重字。
- 进度、潮位和任务条统一为 8pt 圆头：实心表示本地在席，斜纹只表示离开后的远程同步，不能把斜纹当作纯装饰。
- 任务卡底色永久由 Agent 身份决定；待判断只叠加琥珀状态 pill、浮标光晕和深海 CTA，不允许整卡改成黄色。
- 全局主要入场使用约 0.44-0.55 秒 spring；进度条从左生长、数字轻弹入。Anchor 主按钮使用厚环、内高光、底部实体阴影和按压下沉，外圈承担“投锚涟漪”。
- 糖果比例保持 70/30：首页、我的和确认反馈使用高饱和 Agent 色；离开与返航使用低饱和海雾底和深海卡，不让玩味削弱信任感。

### 横屏 Ambient 实现契约

- `LandscapeAmbientDashboard` 是横屏专用编排；任务数据和交互仍复用 `TaskWidgetGrid / TaskWidget`，不要在 SwiftUI 中建立第二套任务状态模型。
- **瞥读层**：时钟、专注时长、总体推进和任务主指标使用约 28-38pt 数字；每个任务只保留名称、主指标、指标含义和进度。
- **环境层**：顶部只保留时钟与专注时长；屏幕顶边用 2pt 分段进度光带表达各 Agent，待判断时仅右边缘进行黄色呼吸。
- **事件层**：底部 ticker 常驻显示最近完成或状态变化，不要求用户打开日志；按住、悬停或聚焦时暂停滚动。
- 横屏点击任意任务只更新右侧 inline 详情，不弹出模态 Sheet，也不遮挡左侧进程视野。存在待判断任务时，右栏默认成为该 Agent 底色的判断席，并用琥珀浮标表达紧急性；确认后立即回到带 Anchor 角色的“无需处理”。
- 横屏是投锚完成后的只读 Ambient 状态，不再提供投锚入口；判断操作全部在右侧 inline 面板内完成。
- `anchor-device`、`anchor-goal`、`anchor-task-{id}` 是旋转连续性的共享几何身份；`anchor-primary-action` 只存在于竖屏并在旋转时退出。SwiftUI 对应使用同一 `Namespace` 下的 `matchedGeometryEffect`，建议时长约 0.52 秒、ease-in-out 曲线。
- 任务数量与 `2×2 / 4×2 / 2×4 / 4×4` 尺寸仍由同一小组件状态驱动；Ambient 只改变信息密度，不改变任务身份、进度或点击行为。
