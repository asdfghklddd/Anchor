# Product source package

`Prototype/` contains the curated contents imported from the product archive on
2026-08-04. It is the product and interaction reference for the native Anchor
implementation.

Included:

- `Anchor.pdf` - original two-page product definition.
- `主视觉设计方案.png` and `核心参考Figma.png` - early visual and flow references.
- `src/` - current React implementation of the high-fidelity iOS prototype.
- `output/playwright/` - portrait, landscape, handoff, return, decision, setup,
  profile, and responsive reference captures.
- `LOGO.png`, the local Nunito font and its OFL license.
- `package.json` and `package-lock.json` for reproducible prototype dependencies.

Excluded from version control:

- `node_modules/` because dependencies are recreated with `npm ci`.
- `dist/` because it is generated by `npm run build`.
- `backups/` and the nested pre-high-fidelity archive because the current source
  and screenshots supersede them.
- the original top-level `ANCHOR.zip`, which remains a local import artifact.

The web prototype is a behavior and visual specification, not production app
architecture. Native code should reuse its product states and design contract,
not translate its single-file React state container line for line.
